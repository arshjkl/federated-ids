# Evaluation

## Metrics

For each model (centralized, manual FedAvg, DP-FedAvg), the following are computed on the held-out test set:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix (TP, TN, FP, FN)
- FPR, FNR (federated results)
